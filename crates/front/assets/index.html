        Microphone denoiser

        Levels are the signal either side of our node, measured on the render thread that runs it. The cost is the wall clock between the node before it returning and the node after it being entered, so it is the denoiser's own time and not a figure from a data sheet; the audio budget is that cost against the 2.67 ms the browser allows per block. A tilde marks a cost estimated from a whole-millisecond clock, which is all Chrome's render thread offers. Keeping up needs no such clock: it is the audio this machine produced against the wall time it took, and past 125 % for three seconds the node comes out. A dash means the browser would not give the number up; hover it to read why.

          Every number here is the browser's own, sampled once a second. A dash is a value this browser did not report; hover it to read why. The tiles carry the video while this view is open, so a track is never attached twice.

          Noise suppression

            One suppressor at a time. Two in series sound worse than either alone, so the browser's own noise suppression and voice isolation are turned off whenever ours is running, and they are not offered separately. Echo cancellation is not part of this choice and stays on.

            The browser's own processing

              These are constraints handed to the browser before the audio is encoded. The server forwards encoded packets and never decodes them, so nothing here can be undone or improved later.
